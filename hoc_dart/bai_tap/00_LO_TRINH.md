# 🎯 Lộ trình học Dart: từ con số 0 đến sẵn sàng học Flutter

## Cách học mỗi bài
1. Đọc phần **📖 LÝ THUYẾT** ở đầu file
2. Chạy thử **VÍ DỤ MẪU**, sửa vài chỗ cho quen
3. Làm từng bài có chữ `// TODO`, theo thứ tự ⭐ → ⭐⭐ → ⭐⭐⭐
4. So kết quả in ra với **"Kết quả mong đợi"** ghi trong đề
5. Bí quá thì đọc lại lý thuyết, gõ thử từng dòng nhỏ, rồi hãy hỏi

▶️ Chạy một bài: `dart run hoc_dart/bai_tap/bai01_hello_print.dart`
